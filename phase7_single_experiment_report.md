# Phase 7 single experiment report: rank-64 slice-preserving hybrid

Date: 7 September 2026  
Status: rejected for accuracy; research-only diagnostic

## Candidate

`candidates/estimator_p7_hybrid_k64.py` implements one fixed configuration from the Phase 7 plan:

- start online compression after nonlinear layer 3;
- retain a rank-64 Tucker representation of the older all-distinct third-cumulant state;
- preserve current diagonal and repeated K3 slices through an explicit `Sym(I,V)` summary;
- retain the newest path/slice birth contribution explicitly;
- use scalar fourth-order state and the Phase 6.5 nonlinear recurrence;
- no labels, truth data, cached centers, or network-specific offline state.

The source was generated by `whest-starterkit/scripts/build_p7_hybrid.py` from the frozen Phase 6.5 finalist. The original control source was hash-checked before generation.

## Verification

`uv run whest validate --estimator ../candidates/estimator_p7_hybrid_k64.py` passed the estimator contract: class loading, setup, `(2,4)` smoke shape, and finite output.

The independent dense checks passed for factor diagonal/repeated slices, mixed contractions, DS contractions, Tucker contractions, factor/DS/core projection, and full-basis slice reconstruction. A depth-16 full-basis recurrence showed maximum float32 drift `1.54e-6`; this is recorded as a numerical diagnostic rather than exact parity.

No AIcrowd submission was made.

## Fixed eight-network diagnostic result

Command: `uv run whest run --estimator ../candidates/estimator_p7_hybrid_k64.py --dataset ../datasets/mini --split mini --n-mlps 8 --runner local --format json --no-residual-wall-time-limit --wall-time-limit 120`

| Metric | Phase 6.5 control | Hybrid result | Change |
|---|---:|---:|---:|
| Mean final raw MSE | `3.7854e-8` | `5.9796e-7` | `15.80x` worse |
| Mean billed utilization | `78.6819%` | `19.0520%` | `75.79%` lower |
| Projected adjusted product | `2.9784e-8` | `1.1392e-7` | `3.83x` worse |
| Failed MLPs in this relaxed diagnostic | 0 | 0 | — |

The hybrid used `418,958,110,787` FLOPs per MLP. Its best and worst per-network adjusted scores were `9.4711e-8` and `1.2873e-7`.

The run used `--no-residual-wall-time-limit` for diagnostic capture. The reported result is therefore **not a valid local submission score**. The ordinary local run also required several seconds per MLP; residual-cap compliance was not established. The candidate is rejected for release and submission.

## Interpretation

This configuration cut factor-state cost too early. Preserving current-layer slices did not preserve the all-distinct information that later weight mixing needs. At rank 64 from layer 3, the lost information dominates the final error. The result does not reject later compression, larger/adaptive cores, or compression starting near the final layers; it rejects this particular aggressive fixed-memory policy.

The next sensible bounded test, if resumed, is a late-start hybrid after layer 10 or 11 with a larger core and no repeated compression before that point. It should be compared against a matched uncompressed suffix and should not be treated as a continuation of this failed candidate.
